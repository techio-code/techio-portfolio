# 茶寮 てちお（さりょう てちお）— ポートフォリオ

**一服のAI、現場の作法で。**

建設業20年の現場経験を、AIに移植して18本のアプリを生み出した個人開発工房「茶寮 てちお」のブランドポートフォリオサイト。

## 公開URL

https://techio-code.github.io/techio-portfolio/

## コンセプト

- 「現場の作法を、コードに移植する。」
- 京都の町家と建設現場を重ねた和モダンの世界観
- 障子越しの自然光、葉影、余白の美

## 構成

5セクションのワンスクロールLP:

1. **物語（STORY）** — 「現場の作法を、コードに移植する。」
2. **作品（WORKS）** — 全十八品（4章構成）
   - 第一章「現場の便利帳」（建設・現場系）
   - 第二章「暮らしの相談所」（生活・感情系）
   - 第三章「仕事の道具箱」（ビジネス系）
   - 第四章「一服の慰み」（ASMR・遊び系）
3. **工房（STUDIO）** — 「現場と画面の、あいだに立つ。」
4. **連絡（CONTACT）** — お声がけください。
